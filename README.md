# 🛒 E-Commerce Sales Analysis (Olist Dataset)

## 📌 Overview
Analisis data penjualan e-commerce Brazil menggunakan dataset Olist (2016-2018).

## 🛠️ Tools
Python | Pandas | Matplotlib | Seaborn | Google Colab

## 📊 Key Findings
- Health & Beauty adalah kategori #1 dengan revenue $1.28M
- Furniture Decor kategori paling rugi (-$26,796)
- Sao Paulo (SP) dominasi 38% total revenue nasional
- Hanya 43.3% transaksi yang profitable
